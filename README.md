## 編碼規則

### 字碼

「=」代表特殊鍵。

|根數|取碼法|例子|
|:-:|:-:|:-:|
|一根|Aa|爲=手①<br>爲：手①。為：手①。为：手①。|
|二根|AaBb|宀=京㊃。豕=牛㊇。<br>家：京㊃牛㊇|
|三根|AaBC=|木=木㊆。目=心㊂。心=心㊃。<br>想：木㊆心心特|
|四根|ABCD=|應：京人隹心特|
|四根以上|ABYZ=|機：木幺戈人特|

### 詞碼

單根字的組詞碼是「Aaa」、比如方的組詞碼就是「行㊂㊂」。

|字數|取碼法|例子|
|:-:|:-:|:-:|
|二字|AaAcBaBc|規律：大心行事<br>方案：行㊂京大|
|三字|AaBaBcCaCc|不知道：艸戈口止心<br>對不起：工艸㊇止子|
|四字|AaBaCaDaDc|飲水思源：食水心水水<br>似水流年：人水水木㈣|
|四字以上|AaBaCaDaEa|中華人民共和國：十艸人事手<br>一氧化二氫：十水人十水|

## 簡碼

簡碼全部依據字頻自動生成。

重碼時、最常用的一个字保留編碼、其餘的字換下一个取碼法再試一次。
